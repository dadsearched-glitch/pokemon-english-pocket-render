# Pocket English Battle V3 — 소스·교육·게임 검토

검토일: 2026-09-29 (뉴질랜드). 대상: 연결된 `Pocket_English_BATTLE_V3_MAX_UPGRADE_20260921` 폴더.

사용자 상황: 뉴질랜드에 온 지 약 8개월, 완전 입문은 아니며 어느 정도 의사소통이 가능함. 게임은 주로 혼자 플레이함. 실제 학년·영역별 수준·플레이 시간은 확인하지 않았음.

## 판단

이 폴더로 수정, 로컬 실행, 테스트, 배포 준비를 이어갈 수 있다. 원래 채팅방을 찾는 것이 필수 조건은 아니다. 학습 자료와 카드 수집, 저장·이전, 솔로 및 멀티플레이 코드가 함께 있다.

학교생활 영어를 반복하고 영어 게임에 참여하는 보조 도구로는 좋은 기반이다. 현재 아이들의 사용 방식에는 **솔로에서 오래 즐길 목표와 보상, 기억을 확인하는 복습, 실제 상황에서 자기 문장을 만드는 연습**이 가장 필요한 개선이다. 새 학년이나 멀티 모드를 더 늘리는 작업보다 우선순위가 높다.

이번에는 게임 소스를 수정하거나 배포하지 않았다. 기존 `dist/`를 빌드로 재생성했고 원본과의 일치를 확인했다. 추가한 것은 이 검토 폴더의 보고서·재현 자료·화면 증거이다.

따라서 **로컬 수정·검증은 지금 가능**, **기존 운영 서비스에 재배포하는 연결은 Render URL/연결 저장소 확인 후 확정**할 수 있다. 새 서비스를 임의로 만드는 것은 필요하지 않다.

폴더의 오래된 문서가 현재 배포를 입증하지는 않는다. `DEPLOYMENT_VERIFIED_KO.md`와 `V8_DEPLOYMENT_RECEIPT.json`은 예전 ChatGPT Sites v8 배포 기록이다. `BATTLE_V3_MAX_UPGRADE_REPORT.md`의 미배포 표기는 작성 당시 기록이며, 사용자가 이후 Render에 배포한 사실을 부정하는 근거가 아니다.

`README.md`에는 미해결 병합 표시(`<<<<<<< HEAD`, `>>>>>>> origin/main`)가 남아 있다. 실행 원본에서 같은 병합 표시를 확인한 것은 아니며, 이것만으로 실행 불능이라고 판단하지 않는다. 다만 다음 수정 때 시작 안내와 배포 문서는 현재 코드에 맞게 정리해야 한다.

## 학습 구성과 장점

6개 학년 × 24단원 = 144단원, 학년별 핵심 어휘 96개, 총 576개의 서로 다른 핵심 어휘이다. 각 단원은 4개의 단어와 2개의 중심 문장, 짧은 지문, 이해 문제를 갖는다.

| 단계 | 기본 내용 |
|---|---|
| Vocabulary | 단어 4개 소개 → 의미 고르기 4개 |
| Listening | 문장의 의도 이해 1개 + 들은 문장 고르기 1개 |
| Reading | 같은 지문에서 정보 찾기·추론 2개 |
| Sentence | 주어진 낱말로 문장 배열 1개 |
| Speaking | 제시 문장 2개 따라 말하기, 인식 또는 자기 확인 |
| Review | 현재 단어 4개 + 과거 복습 단어 최대 2개 + 필요한 재시도 |

추가 복습·재시도가 없을 때 단원별 응답은 15개이다. 학년별 지문 길이는 실제 본문 기준 Year 1: 24~27단어, Year 2: 33~40, Year 3: 41~59, Year 4: 57~74, Year 5: 65~77, Year 6: 82~96이다. 학년 표시는 앱의 단계이며 개인의 영어 수준이나 공식 교육과정 이수를 인증하는 지표가 아니다.

좋은 부분:

- 학교 준비, 친구에게 부탁하기, 빌리기, 길 찾기, 감정, 환경 등 실제 생활에 쓸 주제가 있다. 예: `May I borrow your pencil, please?`, `Could you clarify the final instruction, please?`.
- 같은 핵심 표현을 듣기·읽기·문장·말하기로 연결한다. 무관한 단어만 나열하는 구성은 아니다.
- Year 1~3은 한국어 의미 지원, Year 4는 단계적 영어 정의 전환, 높은 단계에는 근거·비교·관점이 포함된다.
- Molly 고정 음성과 느리게 듣기 기능이 있다.
- 1·3·7·14·30일 복습 간격, 같은 날 성공으로 숙련 단계를 반복 상승시키지 않는 규칙, 오답·도움 사용 후 재확인이 이미 있다.
- 솔로 전투의 어휘 정오답도 `reviewWord`에 기록된다. 이 연결은 유지할 가치가 있다. Together 답안은 현재 같은 복습 기록 갱신 경로를 사용하지 않는다.
- 틀렸다고 카드나 수집물을 잃지 않는다. 학습 완료 보상과 이미 끝낸 미션의 반복 보상은 구분한다.

교육적으로 남은 부분:

- 객관식 의미 인식과 정해진 문장 따라 하기가 중심이다. 자유롭게 표현을 떠올려 말하는 능력을 직접 확인하는 과정은 적다.
- 모든 단원의 여섯 단계 형식이 같아 장기 사용에서 단조로울 수 있다. 이는 사용성 추정이며 실제 아이의 이탈률을 측정한 결과는 아니다.
- 오답 설명은 대체로 “다시 해봐요”, 두 번 이후 정답 힌트이다. 왜 틀렸는지·어떤 문장에 근거가 있는지 설명은 부족하다.
- 듣기에서 글로 보기로 전환할 수 있지만, 해당 완료를 독립적인 듣기 성공과 별도 집계하지 않는다. Speaking의 인식 성공과 자기 확인은 별도 횟수로 기록한다.
- 부모 요약은 단어 숙련·복습·도움 기록에는 유용하지만, 듣기·읽기·자기 문장 말하기를 구분한 변화는 보여주지 않는다.
- 24개 표본 단원(각 학년 U1/8/16/24)을 검토했다. 144단원 전부에 대한 교사 수준의 의미·자연스러움 교정이나 전체 MP3 청취를 완료했다는 뜻은 아니다.

## 게임 구성과 솔로 플레이의 한계

기본 순환은 학습 6미션 → 60 XP·팩 1개 → 카드 5장 → 3장 팀 구성 → 전투이다. 솔로 승리는 20 XP를 준다. 팩에는 EX와 특별 일러스트 보장이 있고, 미보유 카드 우선 선택 장치가 있다. 카드 310종 중 291종이 전투 가능하며 나머지는 수집용이다.

Together에는 실제 사람 1v1, 실제 사람 4명 2v2, 2인 보스 레이드, 2인 던전, 사람 2명 대 AI 2명의 태그가 있다. 레이드는 6계열·각 5단계, 던전은 3테마이다. PVP는 승리 3메달/그 외 2메달, 팩 조각 0이며, 협동 성공은 모드별 하루 첫 성공에 조각 1개를 준다. 5조각으로 팩을 만든다. 파트너 유대와 치장 상점도 있다.

솔로 위주인 현재 사용자에게는 다음 한계가 크다.

1. **한 학년의 학습 보상은 총 24팩, 120장까지이다.** 중복이 있으므로 실제 새 카드 종류는 그보다 적다. 같은 미션 반복과 솔로 승리로 팩이 늘지 않는다. 이 규칙은 중복 보상 남용 방지에는 좋지만, 그 학년을 끝낸 뒤에도 복습하며 수집을 이어갈 보상 경로가 부족하다. 다른 학년으로 바꾸어 새 미션 보상을 받을 수 있으나, 팩을 위해 맞지 않는 수준의 학습을 시키는 방향은 권하지 않는다.
2. **일반 팩은 A1 카드 286종만 제공한다.** 별도 기존 카드 24종의 신규 획득 경로는 2인 레이드 첫 클리어 보상이다. 기존 저장을 가져온 경우는 별개지만, 새 프로필의 정상 솔로 플레이만으로 310종 도감 완성은 불가능하다.
3. **솔로 전투는 훈련전 중심이다.** 상대 셋의 HP는 각 80이며 상대 공격도 고정 규칙이다. 전투 횟수로 상대는 바뀌지만, 지도 진행에 따른 솔로 보스·난이도·새 행동 패턴은 없다.
4. **카드의 역할 차이가 작다.** HP·타입·그림 차이는 있지만 A1의 기술은 주로 타입별 공통 이름과 공통 공격 계산을 쓴다. 수집의 시각적 즐거움에 비해 전술적 차이는 제한적이다. 간단함 자체는 장점이므로 복잡한 카드게임 규칙 전체를 도입할 필요는 없다.

## 현재 아이들에게 추천하는 수정 순서

### 1. 현재 게임을 신뢰할 수 있게 정리

정답 위치 패턴, 의미 반전 말하기 통과, 솔로 안내 대비를 먼저 고친다. 저장·학년 진도·카드·기존 음성을 보존하고 필요한 회귀 검사를 한다. Render 운영본과 로컬 원본을 비교한 후 수정 기준을 고정한다.

### 2. 혼자 매일 돌아올 이유 추가

- 홈의 첫 행동을 “오늘의 짧은 모험”으로 단순화한다.
- 이미 배운 복습 단어 2~4개 + 생활 표현 1개 + 짧은 솔로 도전을 한 묶음으로 만든다.
- 보상은 하루 첫 의미 있는 복습/도전 완료에 제한해 같은 답 무한 클릭을 유도하지 않는다. 기존 팩 확률을 크게 올리기보다 작은 조각 보상과 명확한 수집 목표를 연결한다.
- 기존 24종 카드에 솔로 도전 획득 경로를 추가하거나, A1 수집과 레이드 수집 목표를 분리해서 보여준다. 주로 혼자 하는 아이에게는 전자가 더 적합하다.
- 진행 지역마다 작은 보스를 두고 “다음에 무엇을 만나나”를 보여준다. 기존 사람 4명 2v2는 별도 모드로 유지한다.

### 3. 아는 표현을 실제로 써보게 만들기

주어진 문장 따라 말하기 뒤에 짧은 변형 한 번을 더한다. 예를 들어 연필을 빌린 뒤 책이나 지우개로 대상을 바꾸어 요청한다. 학교에서 못 들었을 때 다시 말해 달라고 하기, 친구 놀이에 끼어들기, 규칙 묻기, 의견과 이유 말하기를 NPC 상황 선택이나 문장 틀로 연습한다.

처음부터 자유 대화 AI·실시간 음성 서버를 추가할 필요는 없다. 정해진 상황과 여러 허용 답을 사용하는 방식으로도 현재의 객관식/따라 읽기와 다른 연습을 만들 수 있다. 이 제안은 기능 설계이며 아직 구현된 기능이 아니다.

### 4. 수준과 성장을 더 잘 보여주기

아이의 실제 학교 학년만으로 학습 Year를 정하지 않는다. 두세 단원을 보며 단어는 쉽게 아는지, 듣기만으로 이해하는지, 힌트 없이 한 문장을 말할 수 있는지를 나누어 본다. 처음에는 짧은 진단/체험으로 추천하고 보호자가 바꿀 수 있게 한다.

부모 요약에는 “미션을 몇 개 끝냈는지”와 “며칠 뒤에도 도움 없이 맞히는지”를 분리해서 표시한다. 듣기 대체 읽기와 Speaking 자기 확인은 유용한 지원이므로 없애지 말고 실제 수행 방식으로 표시한다.

### 5. 그다음 전투 다양성

솔로 보스의 다음 행동 예고, 쉬운 공격/방어/회복 역할, 타입별 작은 장점을 검토한다. 복잡한 능력치 성장·강한 희귀 카드 의존보다 좋아하는 포켓몬을 쓸 이유를 만드는 편이 이 게임에 어울린다. 저학년의 읽기 시간을 압박하는 타이머는 기본으로 추가하지 않는다.

이 방향은 복습 간격과 기억에서 꺼내는 연습을 권하는 [IES 학습 지침](https://ies.ed.gov/ncee/wwc/PracticeGuide/1), 의미 있는 언어 사용과 상호작용을 강조하는 [EEF 구어 언어 자료](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/oral-language-interventions)를 참고한 설계 제안이다. 이 자료가 현재 게임의 학습 효과를 직접 검증한 것은 아니다.

## 다음 작업을 시작할 때

1. 이 보고서를 현재 검토 기준으로 읽는다. 옛 인계문의 배포 상태를 현재 상태로 덮어쓰지 않는다.
2. Render URL·연결된 Git 저장소·배포 브랜치를 확인하고 화면 버전뿐 아니라 주요 파일을 비교한다.
3. 운영 프로필은 기존 사이트의 설정에서 백업할 수 있다. 주소/브라우저가 바뀌면 기존 기록이 자동 이동한다고 가정하지 않는다.
4. 위의 우선 수정 후보를 좁게 적용하고, 저장·학습·전투 검증 후 아이들이 쓰는 실제 기기에서 확인한다.
5. 실제 배포는 수정 결과와 대상 서비스가 확정된 다음 수행한다. 이번 검토에서는 배포하지 않았다.
